feat: smart auto-fill system with conversation history sidebar

This PR introduces a comprehensive smart auto-fill system that automatically
captures interviewer questions and provides intelligent question detection,
along with a redesigned conversation history sidebar.

## New Features

### Smart Auto-Fill System
- Auto-fills input box with interviewer (Them channel) speech in real-time
- Smart question completeness detection using behavioral interview patterns
- Visual states for question readiness:
  - `stt-filling`: Actively receiving speech (green border pulse)
  - `stt-accumulating`: Building up text (subtle animation)
  - `stt-ready`: Question looks complete (solid green, "Ready to answer" indicator)
  - `stt-dimmed`: User speaking, may clear soon (dimmed state)

### Soft Clear Behavior
- When user speaks, doesn't immediately wipe the question
- Waits 2.5s to see if user is just acknowledging vs actually answering
- Preserves question if user only speaks briefly

### Question History & Undo
- Saves questions to history before clearing (max 10 items)
- Ctrl+Z / Cmd+Z restores last question when input is empty
- Escape key clears input with undo hint toast
- History badge on toggle button shows saved question count

### Floating Conversation History Sidebar
- Redesigned as external floating panel (doesn't overlap main UI)
- Manual toggle via history button (message icon in composer)
- Glass morphism styling matching main panel
- Slide-in animation, positioned at right edge of screen
- Auto-scrolls to bottom when opened

### Keyboard Shortcuts
- Ctrl+Shift+A / Cmd+Shift+A: Force-answer current question immediately
- Ctrl+Z / Cmd+Z: Restore last question (when input empty)
- Escape: Clear input with undo hint

### Visual Improvements
- Send button turns green when question is ready
- Small green listening indicator dot on composer when capture active
- Interim transcription preview shown above input (grayed italic)
- History button shows badge with question count
